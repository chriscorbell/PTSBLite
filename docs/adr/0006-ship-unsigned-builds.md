# ADR-0006: Desktop code-signing policy

- **Status:** Superseded by ADR-0014
- **Date:** 2026-07-26
- **Superseded:** 2026-08-16

This ADR formerly governed signing and distribution for Windows, macOS, and Linux desktop
artifacts. ADR-0014 removed the desktop product, packaging configuration, and release workflow from
the repository. PTSBuilderLite is a browser application and has no installable artifacts.
